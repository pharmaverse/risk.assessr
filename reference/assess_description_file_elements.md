# assess_description_file_elements

assess_description_file_elements

## Usage

``` r
assess_description_file_elements(pkg_name, pkg_source_path)
```

## Arguments

- pkg_name:

  \- name of the package

- pkg_source_path:

  \- pkg_source_path - source path for install local

## Value

\- list - list with scores for description file elements
