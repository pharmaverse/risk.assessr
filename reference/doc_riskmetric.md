# Run all relevant documentation riskmetric checks

Run all relevant documentation riskmetric checks

## Usage

``` r
doc_riskmetric(pkg_name, pkg_ver, pkg_source_path)
```

## Arguments

- pkg_name:

  name of the package

- pkg_ver:

  version of the package

- pkg_source_path:

  path to package source code (untarred)

## Value

raw riskmetric outputs
