# Extract Risk Inputs

Compute intermediate risk input values from flattened package data.

## Usage

``` r
extract_risk_inputs(flat_data)
```

## Arguments

- flat_data:

  Flat package data as returned by
  [`normalize_data()`](https://pharmaverse.github.io/risk.assessr/reference/normalize_data.md).

## Value

A list of computed values required for risk scoring.
