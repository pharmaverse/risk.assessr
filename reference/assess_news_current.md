# Assess Rd files for news

Assess Rd files for news

## Usage

``` r
assess_news_current(pkg_name, pkg_ver, pkg_source_path)
```

## Arguments

- pkg_name:

  \- name of the package

- pkg_ver:

  \- package version

- pkg_source_path:

  \- source path for install local

## Value

news_current - variable with score
