# Create empty results

This creates an empty results list for all risk metrics

## Usage

``` r
create_empty_results(pkg_name, pkg_ver, pkg_source_path, metadata)
```

## Arguments

- pkg_name:

  package name

- pkg_ver:

  package version

- pkg_source_path:

  package source path

- metadata:

  list with metadata

## Value

\- list with empty risk profile values
